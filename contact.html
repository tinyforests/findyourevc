Data Sources

This tool uses open data from the Victorian Government's spatial data platform. EVC classifications are sourced from the Native Vegetation 2005 Ecological Vegetation Classes dataset.

For authoritative EVC determinations, planning requirements, or site-specific assessments, refer to Nature Kit or consult qualified environmental professionals.

Reporting Issues

If you encounter discrepancies between this tool's results and Nature Kit, or if you have technical questions about the classification methodology, you can report them directly through the result interface using the "Report mismatch" button.

Technical Queries

For questions about the tool's implementation, data processing methodology, or API integration, contact hello@gardenerandson.com.au

Appropriate Use

This tool is intended for:

• Preliminary ecological research and education

• Garden planning and indigenous plant selection

• Understanding local ecological heritage

This tool is not appropriate for:

• Planning permit applications

• Regulatory compliance determinations

• Legal or contractual purposes

• Site-specific ecological assessments
